# Research Track — Symptom Image CNN Fine-Tuning

This directory contains research notebooks, dataset annotations, transfer learning scripts, and image augmentation routines for Path A (Symptom Photo CNN).

## Anatomical Targets
1. **Palpebral Conjunctiva (Eyes):** Conjunctival pallor classification for Anemia detection.
2. **Nail Beds:** Koilonychia (spoon nails) and pallor detection for Iron deficiency.
3. **Tongue:** Atrophic glossitis / smooth tongue manifestation for Vitamin B12 / Folate deficiency.
4. **Palms / Skin:** Skin pallor indices.

## Datasets & Transfer Learning Model Architectures
- Pretrained Backbones: `ResNet-50`, `EfficientNet-B0`, `MobileNetV3`.
- Datasets stored locally under `research/datasets/`.
